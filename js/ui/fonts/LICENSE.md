# Fonts

Latin subsets from Fontsource 5.3.0, as slowboard.io uses them (`slowboard-site`'s
`node_modules/@fontsource*`). All four are under the SIL Open Font License 1.1
(https://openfontlicense.org).

| File | Family | Use on the page |
|---|---|---|
| `chivo-latin-wght-normal.woff2` | Chivo (variable) | everything people read |
| `press-start-2p-latin-400-normal.woff2` | Press Start 2P | page titles and key legends only |
| `silkscreen-latin-400-normal.woff2` | Silkscreen | the wordmark, labels and buttons |
| `vt323-latin-400-normal.woff2` | VT323 | numbers, times and codes, at 20 px or more |
